# 0017. 「このアプリについて」と「ライセンス」には、ホーム画面と同じアイコンを出す

- 状態: 採用
- 日付: 2026-11-05

## 文脈

「このアプリについて」と「ライセンス」の画面は、アプリ名の下に、Material の汎用の絵
（`Icons.web_asset`。青い窓の形）を水色の角丸の上に出していた。雛形の仮置きのまま派生アプリにも
そのまま渡り、どのアプリでも同じ絵が出ていた。持ち主から「アプリ名の後のアイコンが謎」と言われた。
ホーム画面のアイコンとは似ても似つかず、何の絵か分からない。

## 決定

1. 2 つの画面はどちらも `AppIdentityIcon`（`lib/presentation/widgets/ui/app_identity_icon.dart`）を出す。
   中身は `assets/icon/app_icon.png`——`flutter_launcher_icons` がホーム画面のアイコンを作る元の絵——を
   角を丸めて 80 の大きさで描いたもの。
2. 派生アプリはアイコンの元の絵を差し替えるだけで、2 つの画面も同じ絵になる。コードは触らない。
3. pubspec の `flutter_launcher_icons.image_path` と `AppIdentityIcon.asset` がずれたら試験が落とす。

## 理由

- アプリを紹介する画面に出す絵は、利用者がホーム画面で見ている絵と同じであるべき。別の絵を出すと
  「これは何か」を考えさせる。
- アイコンの元の絵は派生アプリが必ず差し替える（ホーム画面に出るので差し替え忘れに気付く）。それを
  読めば、派生アプリごとに画面を直す手間が無い。
- 汎用の絵を派生アプリごとに選んでもらう案は、選ばれずに仮置きが残る（今回そうなった）ので採らなかった。

## 影響

- 白いアイコンが白い画面に溶けないよう、縁に細い線（`outlineVariant`）を引く。
- 色の名前 `AppColors.brandContainer` は 2 つの画面では使わなくなった（色の一覧には残す）。
